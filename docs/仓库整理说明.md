# GitHub 目录整理说明

此目录由现行 SmartMedicineBox 工程另建副本，供 GitHub 源码仓库使用。比赛提交的“全部代码.rar”仍为完整归档，内容不变。

- 原样保留 180 项源码、字模、IP 和约束输入，以及已确认的主 bit。
- 保留 TD 工程策略，移除工程根节点中的旧绝对路径；文件引用仍采用相对路径。
- 排除 TD 构建数据库、缓存、重复工程 ZIP 和生成的综合网表；保留已有测试源码、独立参考和验证收据。
- 仿真辅助脚本在仓库根查找可选运行库，缺少时提示如何获取；原测试逻辑不变。
- 默认文件检查入口改为适用于此目录的检查脚本，不要求旧 Runs 数据库或完整比赛归档。
- 大附件单独上传到 GitHub Releases，按 README 放回对应位置后使用。

目录整理没有重新编译工程，也没有操作开发板、Flash、TF 卡或串口。
